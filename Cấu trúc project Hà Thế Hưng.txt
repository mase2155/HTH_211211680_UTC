Thứ tự thực hiện (bám kế hoạch đề cương):
1. Code backend + CSDL + frontend (Chương 4)  ← đang làm
2. Kiểm thử Postman + kịch bản giao diện     ← bước tiếp theo khi code xong
3. Tích hợp, sửa lỗi, chạy ổn định local      ← “hoàn thiện hệ thống”

Ghi chú về “triển khai” trong đề cương:
- Chương 4 tên “Xây dựng và triển khai hệ thống” nghĩa là VIẾT và CHẠY được
  Backend API, kết nối SQL Server, giao diện React — không bắt buộc thuê host.
- Công cụ trong đề cương: VS Code, SSMS, Postman, Figma, Draw.io, Git/GitLab.
  Không yêu cầu deploy Vercel/Azure/Render.
- Kế hoạch mục 6: “Tích hợp, kiểm thử và hoàn thiện” = chạy local, test, sửa lỗi.
- Hướng phát triển (Chương 6.3): cổng thanh toán thật, email… là mở rộng sau,
  không thuộc phạm vi bắt buộc hiện tại.
- Chỉ cần host online nếu giáo viên hướng dẫn yêu cầu thêm khi bảo vệ.
